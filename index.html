HERMETH AGENT

Personal automation agent

앱 소개

HERMETH AGENT는 단일 사용자(소유자 본인)를 위한 개인 자동화 에이전트입니다. 사용자가 명시적으로 승인한 자신의 Google 계정 데이터에 한해 동작하며, 다음과 같은 개인 작업을 자동화합니다.

하는 일

  • Google Drive에 저장된 본인의 문서를 목록으로 조회하고, 필요 시 업로드·다운로드합니다.
  • Google Calendar의 일정을 읽어 하루 브리핑을 만듭니다.
  • 본인의 Gmail을 검색·조회하고, 알림 메일을 보냅니다.
  • Sheets·Docs 문서를 읽고 작성합니다.
