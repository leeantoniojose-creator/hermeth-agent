개인정보처리방침

최종 업데이트: 2026년 10월 10일

HERMETH AGENT(이하 "본 앱")는 단일 사용자 본인의 개인 자동화 도구입니다. 본 앱은 Google API Services User Data Policy(Google API 서비스 사용자 데이터 정책)와 그 제한적 사용(Limited Use) 요구사항을 준수합니다. 본 방침은 본 앱이 Google 사용자 데이터에 어떻게 접근·사용·보관·공유·삭제하는지 설명합니다.

1. 접근하는 Google 사용자 데이터

본 앱은 사용자가 OAuth 동의 화면에서 명시적으로 승인한 범위에 한해서만 데이터에 접근합니다.

범위(scope)접근 대상사용 목적
auth/driveGoogle Drive 파일 및 폴더본인 문서 조회·업로드·다운로드
auth/calendarGoogle Calendar 일정일정 조회 및 브리핑 생성
auth/gmail.readonlyGmail 메일(읽기)메일 검색·조회
auth/gmail.sendGmail 발신본인이 요청한 알림 메일 발송
auth/gmail.modifyGmail 라벨·읽음 상태메일 정리(라벨·읽음 처리)
auth/spreadsheetsGoogle Sheets시트 읽기·쓰기
auth/documentsGoogle Docs문서 읽기·작성
auth/contacts.readonlyGoogle 주소록(읽기)연락처 조회

2. 데이터 사용 목적

접근한 데이터는 오직 사용자 본인의 요청을 수행하기 위해서만 사용됩니다. 광고, 프로파일링, 신용평가, 대출 심사, 또는 여타 목적으로 사용되지 않습니다. 본 앱은 사용자 데이터를 AI 모델 학습에 사용하지 않습니다.

3. 저장 및 보안

  • OAuth 자격증명(액세스·리프레시 토큰)은 사용자 본인의 PC에 로컬로만 저장됩니다.
  • 토큰은 google_token.json 형태로 저장되며 접근이 제한된 로컬 경로에 위치합니다.
  • 전송 구간은 HTTPS(TLS)로 보호됩니다.
  • Google 사용자 데이터를 판매하거나 데이터 브로커에게 제공하지 않습니다.

4. 제3자 공유

본 앱은 Google 사용자 데이터를 제3자와 공유하지 않습니다. 법령상 의무가 있는 경우 외에는 어떤 외부 주체에도 제공하지 않습니다.

5. 보관 및 삭제

  • 데이터는 본인의 요청을 처리하는 동안에만 일시적으로 처리되며, 별도의 서버에 상시 보관하지 않습니다.
  • 사용자는 Google 계정 권한 페이지에서 언제든지 본 앱의 접근 권한을 취소할 수 있습니다.
  • 권한 취소 또는 로컬 토큰 파일 삭제 시, 본 앱은 더 이상 해당 데이터에 접근할 수 없습니다.
  • 삭제를 요청하려면 아래 문의처로 연락해 주세요.

6. 아동

본 앱은 아동을 대상으로 하지 않으며, 만 14세 미만 사용자의 데이터를 의도적으로 수집하지 않습니다.

7. 방침 변경

본 방침이 변경되면 이 페이지에 갱신된 날짜와 함께 게시됩니다.
